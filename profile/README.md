# sealup

Fast, safe deploys to shared hosting over SFTP, SSH or FTP, from your machine or CI.

sealup is an independent open-source project created and maintained by [Samuel Asensi](https://samuelasensi.com) ([GitHub](https://github.com/sasensi)). It grew out of the shared-hosting deployments in my client work, bringing that workflow into CI with explicit safeguards and reproducible tests.

- [Source code and issues](https://github.com/sealup/sealup)
